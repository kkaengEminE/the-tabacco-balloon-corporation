# The Tobacco Balloon Corporation — 담풍사 (擔風社)

> *Est. 1887, London — Where Victorian elegance meets artificial intelligence.*

19세기 말 런던. 완벽한 쓰리피스 정장을 입은 신사 CEO **애셔 애덤스(Asher Adams)**는 고풍스러운 서재에서 맥북으로 AI 사업을 운영합니다. 파이프 담배의 각성 효과에 의존하며 벌룬(Balloon) 서비스를 성장시키는 **싱글 페이지 웹 타이쿤 시뮬레이션 게임**입니다.

**https://kkaengemine.github.io/the-tabacco-balloon-corporation/**

## How to Play

### 목표

애셔 애덤스를 살려두면서, 담풍사(T.B.C.)를 파산시키지 않고 무한히 성장시키세요. 클리어는 없습니다 — 얼마나 오래 버티느냐가 전부입니다.

### 조작

| 키보드 | 버튼 | 설명 |
|--------|------|------|
| `W` | ⚙ 일하기 | 벌룬 서비스 작업 진행 (꾹 누르기 가능) |
| `S` | 🪈 흡연 | 파이프 담배를 피워 각성 상태 돌입 |
| `E` | 🍽 식사 | 포만감 회복 (£15 소모, 시간 소요) |
| `R` | 🛏 수면 | 수면 게이지가 95%까지 자동 회복 |
| `T` | 🚽 화장실 | 화장실 게이지 회복 (시간 소요) |
| — | 👤 고용 | 직원 고용 (자동 작업 보너스) |
| — | 💊 약 구매 | 생명력 +25%, 담배 수치 -20% |
| — | 🏗 확장 | 준비 중 (다음 업데이트) |

### 애셔의 생존 수치

- **생명력** — 0이 되면 게임 오버. 식사/수면/화장실이 0일 때, 또는 과흡연 시 감소합니다.
- **식사 / 수면 / 화장실** — 실시간으로 계속 감소합니다. 0에 도달하면 생명력이 깎이기 시작합니다.
- **담배** — 흡연 버튼으로 충전. 시간이 지나면 서서히 감소합니다.

### 파이프 담배 시스템 (핵심 메카닉)

| 담배 수치 | 효과 |
|-----------|------|
| 0% ~ 69% | 일반 상태 (작업 속도 ×1.0) |
| 70% ~ 110% | **각성 상태** — 작업 속도 ×2.1 |
| 111% ~ 150% | **고각성** — 작업 속도 ×2.5, 생명력 서서히 감소 |
| 151% ~ 200% | **위험** — 작업 속도 ×3.0, 생명력 빠르게 감소 |

담배를 많이 피울수록 일은 빨리 끝나지만, 과흡연은 애셔를 죽입니다. 약 구매(£80)로 담배 수치를 낮추고 생명력을 회복할 수 있습니다.

### 벌룬 서비스 (비즈니스)

- 메인 벌룬의 고객 수는 **자동으로 감소**합니다 (고객 이탈).
- `일하기`를 클릭하면 작업 진행도가 차고, 100% 달성 시 매출이 발생하며 고객이 증가합니다.
- **직원 고용** 시 자동으로 작업이 진행되어, 플레이어가 다른 일을 할 여유가 생깁니다.

### 엔터프라이즈 계약

- 랜덤하게 **외부 기업 미팅**이 발생합니다.
- 수주하면 보라색 엔터프라이즈 벌룬이 생성되며, 선금의 30%를 즉시 받습니다.
- 엔터 벌룬을 **클릭하여 수치를 유지**해야 합니다. 0이 되면 계약 파기 → 즉시 게임 오버.
- 월말에 엔터 벌룬이 30% 이상이면 나머지 계약금(70%)을 받습니다.

### 월말 정산

게임 내 30일이 지나면 성과 보고서가 출력됩니다:

- 총 노동 시간, 흡연 횟수, 작업 완료 건수
- 매출, 지출, 순이익
- 회원(고객) 수, 직원 수, 계약 수

직원 월급(인당 £100)이 자동 차감됩니다. **잔고가 마이너스면 파산 → 게임 오버.**

### 게임 오버 & 부활

게임 오버 조건:
1. 애셔의 생명력이 0
2. 월말 잔고가 마이너스 (파산)
3. 엔터프라이즈 계약 파기

게임 오버 시 **"광고 시청하고 이어하기"** 버튼이 나타납니다. 5초 대기 후 모든 수치 50%, 자금 0으로 부활합니다. **회차당 딱 1회만 사용 가능.**

## Art Direction

**Victorian Anachronism** — 19세기 빅토리아풍 서재에 현대 맥북과 AI가 공존하는 시공간적 불일치의 매력.

- 기본 색상: 브라운, 딥그린, 골드 (빅토리안 톤)
- 데이터/수치: 네온 그린 (사이버 톤)
- 카이로소프트의 도트 감성 + 돈스타브의 하드코어 생존 UI
